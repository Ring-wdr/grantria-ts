# 릴리즈 노트

데스크톱(Windows 설치 파일)과 Android APK의 버전별 변경 사항입니다. 원본에 없는 기능은 기본값이 원본 동작이고, 게임 메뉴 → 환경설정 → 편의 설정에서 켜고 끕니다.

## 0.1.9 (2026-10-17)

### 끊김 수정 (0.1.8에서 생긴 문제)
- **전투 중 HUD**: 데미지 숫자가 뜨거나 아이콘이 깜빡일 때마다 HUD 요소를 통째로 다시 배치하던 문제를 고쳤습니다. 몹을 연달아 때릴 때 생기던 잔렉이 줄어듭니다.
- **틱 간격**: 게임패드 없이 할 때 틱이 가끔 한 프레임씩 늦거나 일찍 돌아(33·67 ms 간격) 움직임이 고르지 않던 문제를 고쳤습니다.
- **오디오**: 앱을 켜자마자 백그라운드로 보내면 배경음이 계속 나던 문제, 같은 배경음을 멈췄다 다시 틀면 두 곡이 겹쳐 재생되던 문제를 고쳤습니다.

### 저장 데이터
- 슬롯 세이브 형식은 바뀌지 않았습니다.

## 0.1.8 (2026-10-16)

### 원본 재현·수정
- **라이오넬 도서관 3층 포털**: 3층 도서관4에서 3층 도서관3으로 넘어가면 도착 지점이 돌아가는 포털 경계 위라서, 멈춰 서 있으면 곧바로 3층 도서관4로 되돌아가던 문제를 고쳤습니다(원본에도 있던 문제). 5층 으슥한방 → 5층 비밀의방도 같은 이유로 되돌아갔습니다. 이제 맵에 들어온 뒤 포털 밖으로 한 번 나가야 포털이 동작합니다.

### 발열·전력
- **화면 주사율**: Android 앱이 90·120 Hz 화면에서도 같은 해상도의 60 Hz 모드를 요청합니다. 게임은 원래 초당 20틱이라 움직임은 같습니다.
- **그리기 부담**: 스프라이트를 한데 모아 그려 틱당 그리기 호출을 크게 줄였고(오프닝 맵 기준 790 → 88회), 틱이 없는 화면 프레임은 건너뜁니다(게임패드 연결 시에는 매 프레임). HUD는 바뀐 부분만 다시 그립니다.
- **오디오**: 소리가 들리지 않을 때(백그라운드, 볼륨 0)는 오디오를 멈추고, 배경음은 현재·직전 곡만 메모리에 둡니다.

### 개발자 모드
- **성능 기록**: 1분마다 프레임 시간·롱태스크·메모리를 기록하고 JSON으로 내보냅니다(기본 끔).

### 저장 데이터
- 슬롯 세이브 형식은 바뀌지 않았습니다.

## 0.1.7 (2026-10-15)

### 원본 재현·수정 (저장)
- **최종 보스 방 저장**: 입실론을 잡은 뒤 도전과제 팝업을 닫으면 입실론 방에 엔딩 전 상태로 저장되어, 다시 불러오면 입실론부터 다시 잡아야 하던 문제를 고쳤습니다. 원본처럼 보스전 중(전투 결계)·특수 맵·정원·차원의 문에서 하는 저장은 **부분 저장**입니다. 경험치·아이템·골드·퀘스트·도전과제는 저장되고, 위치·지역·이벤트 진행은 마지막 일반 저장 그대로 남습니다. 이때 HP는 최대 HP로 저장됩니다.
- **특수 아이템 사용 저장**: 스탯·스킬·특성 초기화, 특성 스킬 상자, 희귀 보석 상자, 비약 상자, 특수 비약을 쓰면 원본처럼 저장됩니다(부분 저장). 경험치 상자는 "게임 데이터 저장됨"과 함께 저장되고, 저장할 수 없는 곳에서는 저장되지 않습니다.
- **베르무트 처치 저장**: 베르무트를 잡으면 처치 수가 오른 뒤 저장됩니다(부분 저장).
- **되감기 방지**: 저장 전에 쓴 영웅의 물약·부활 주문서·차원 전용 비약은 다시 불러올 때 차감되는데, 이 차감을 곧바로 저장합니다. 저장하지 않고 끄면 아이템이 되살아나던 구멍을 막았습니다.

### 저장 데이터
- 슬롯 세이브 형식은 바뀌지 않았습니다. 이미 입실론 방에 저장된 슬롯은 그대로이며, 불러오면 입실론부터 다시 진행합니다.

## 0.1.6 (2026-10-15)

### 원본 재현·수정
- **특성 미적용**: 특성을 찍고 다시 접속하면 특성 효과(상태이상 내성, HP·MP 등)가 스탯에 빠져 있다가 스탯을 올리거나 장비를 바꿔야 돌아오던 문제를 고쳤습니다. 장착한 칭호 효과도 같은 이유로 빠져 있었는데, 이제 불러오자마자 적용됩니다.
- **장비창 선택지**: 장비 칸을 눌러 나오는 선택지(상세보기·착용하기 등)가 캐릭터 그림에 가려 읽기 어렵던 문제를 고쳤습니다. 선택지가 캐릭터 위에 보입니다.
- **아이템 상세**: 장비의 주 능력치를 원본처럼 옵션(%)을 더한 값과 강화 보너스로 나눠 보여 주고, 강화한 방어구는 강화 효과 줄을 옵션 위에 보여 줍니다. 이름에 붙은 "+N"이 한 번 더 붙지 않습니다.
- **장비 비교**: 착용 장비와 비교할 때 기본 수치만 보던 것을, 원본처럼 옵션과 강화 보너스까지 더해 비교합니다. 방어구 강화 효과 차이도 보여 줍니다.
- **칭호 상세**: 칭호 조건 아래에 장착 효과와 기본(보유) 효과를 보여 주고, 버튼을 원본처럼 칭호장착·칭호해제·취소(가진 칭호) / 확인(없는 칭호)으로 맞췄습니다.
- **하드코어 전환**: 하드코어로 전환하면 도전과제와 업적 카운터가 초기화되어 도전과제 팝업과 보상 골드가 다시 나오던 문제를 고쳤습니다. 원본처럼 그대로 유지됩니다.

### 저장 데이터
- 슬롯 세이브 형식은 바뀌지 않았습니다.

## 0.1.5 (2026-10-15)

### 새 기능
- **조합서 버리기**: 가방 관리에 조합서를 등급별(0~3)로 한 번에 버리는 메뉴를 넣었습니다.

### 원본 재현·수정
- **보스방 진행 막힘**: 보스방에 들어간 뒤 저장되면(맵 이동 자동 저장 등) 다시 불러왔을 때 보스는 사라지고 스토리는 진행되지 않던 문제를 고쳤습니다. 스토리 보스는 처치 이벤트가 끝나기 전까지 다시 나타나고, 잡으면 이야기가 이어집니다.
- **크라켄**: 먹물에 밀려 벽이나 결계 너머 전투 구역 밖으로 나가던 문제를 고쳤습니다. 밀려나도 벽과 결계에서 멈춥니다.
- **퀸 프로스트웜**: 빨려 들어간 뒤 머리 판정 안에 갇혀 움직이지 못하던 문제를 고쳤습니다. 보스 HP 바는 실제로 피해가 들어가는 머리의 HP를 보여 줍니다.
- **마더**: 처치 후 방을 나갔다 오면 다시 나타나던 문제를 고쳤습니다.
- **초반 보스**: 세 사람이 합류한 뒤에는 다른 두 캐릭터의 초반 보스방에 보스가 나오지 않습니다. 합류 뒤 특정 필드 맵의 몬스터도 원본처럼 다음 이야기 전까지 나오지 않습니다.
- **크레이그 협곡 바람의 배리어**: 크리스탈 조각을 가져온 뒤에도 배리어가 길을 막아 비공정으로 갈 수 없던 문제를 고쳤습니다. 배리어가 깨진 뒤에는 깨진 모습으로 보입니다.
- **이펙트**: 공격·스킬 이펙트의 검은 바탕이 그대로 보이던 문제를 고쳤습니다. 원본처럼 스크린·가산 합성으로 그립니다.
- **강조선**: 강한 공격·스킬의 화면 강조선이 가운데로 몰리지 않고 원본처럼 화면 가장자리에 나옵니다. 풀스크린에서는 양옆 강조선이 화면 끝까지 닿습니다.
- **특성의 구슬**: 특성 초기화 물약을 써도 고급상점 구매 횟수(최대 10개)가 초기화되지 않습니다.

### 저장 데이터
- 슬롯 세이브 형식은 바뀌지 않았습니다. 이미 진행이 막힌 세이브도 해당 맵에 다시 들어가면 이어서 진행됩니다.

## 0.1.4 (2026-10-14)

### 새 기능
- **가방 20개**: 쿠폰으로 사는 가방이 2개에서 17개로 늘어 가방을 20개(320칸)까지 씁니다. 인벤토리·상점 목록·창고의 가방 줄은 스크롤되고, 선택한 가방을 따라갑니다.
- **가방 관리**: 가방정리 버튼이 정렬 / 일괄 버리기 / 일괄 분해 메뉴를 엽니다. 일괄 버리기·분해는 강화·보석이 없는 장비를 등급별로 고르며, 유료 아이템·퀘스트 아이템·재료는 고르지 않습니다. 일괄 분해는 낱개 분해처럼 마법 해체기가 있어야 하고, 없으면 쿠폰으로 살지 묻습니다. 확인 창은 「아니오」에서 시작합니다.
- **개발자 모드**: 편의 설정의 「버프 표시」를 연속으로 10번 바꾸면 환경설정에 개발자 모드가 생깁니다. 사냥 경험치 배율(×N은 N마리 처치로 계산)과 드랍 배율(드랍 판정 N번)을 정수로 정하고, 「개발자 모드 닫기」로 ×1로 되돌리고 숨깁니다.

### 수정
- 터치 화면(휴대폰·태블릿)에 대사 로그 버튼이 보이지 않던 문제를 고쳤습니다.
- 가방에서 귀환서를 쓰면 메뉴가 모두 닫히고 바로 귀환합니다.
- 가방 정렬 뒤 바로 가방 화면으로 돌아옵니다.

### 저장 데이터
- 슬롯 세이브 형식은 바뀌지 않았습니다(아이템 목록 하나와 산 가방 수). 개발자 모드 설정은 슬롯 밖에 따로 둡니다.
- 원본 세이브로 내보낼 때는 원본 한도대로 가방 2개(80칸)까지만 들어가며, 넘는 아이템 수를 알려 줍니다.

## 0.1.3 (2026-10-14)

### 새 기능
- **회상 순서도**: 회상 버튼을 누르면 이야기 전체가 순서도로 나옵니다. 세 캐릭터의 오프닝 이야기가 나란히 내려와 초원 고대유적에서 합쳐지고, 그 뒤 공통 길을 장별로 잇습니다. 본 장면만 재생하며, 공통 장면은 고른 시점(캐릭터)으로 봅니다.
- **회상 범위**: 어떤 장면을 봤으면 그 캐릭터의 길에서 그보다 앞선 장면도 모두 다시 볼 수 있습니다. 이전 버전에서 지나간 이야기도 열립니다.
- **이어서 보기**: 회상에서 켜 두면 장면이 끝날 때 다음 장면이 바로 이어집니다. Esc로 멈춥니다.
- **회상의 LOG·AUTO**: 회상 장면에서도 대사 로그와 자동 진행을 씁니다. 로그는 그 장면의 대사만 따로 담습니다.

### 원본 재현·수정
- 착용한 장비가 캐릭터 외형(필드, 장비 탭, 슬롯·랭킹 초상)에 보이지 않던 문제를 고쳤습니다.
- 보스 이벤트에서 주인공이 사라지거나 보스가 두 마리(멈춘 것과 움직이는 것) 보이던 문제를 고쳤습니다. 회상에서도 같습니다.
- 보스 등장 장면 전에는 원본처럼 보스가 보이지 않고, 보스전은 필드 음악이 아니라 보스 음악으로 시작합니다.
- 캐릭터 화면의 AGI 설명이 "아무 효과가 없습니다"로 나오던 문제를 고쳤습니다(직업별 설명).
- 드릴소드가 적에 닿으면 위로 방향을 틀던 동작을 없앴습니다. 시전한 방향으로 공격합니다.
- 산 가방이 상점의 판매·강화 목록에도 모두 나옵니다.
- 상점 수량 창 위로 다른 칸의 소지수가 비치던 문제를 고쳤습니다.
- 공간이동석을 등록하면 등록 전·후 돌이 겹쳐 보이던 문제를 고쳤습니다.
- 타이틀 구름에 격자 선이 보이던 문제와, 등급 안내 화면 가운데가 붉게 보이던 문제를 고쳤습니다.

### 저장 데이터
- 슬롯 세이브와 기록 형식은 바뀌지 않았습니다. 설정에 「이어서 보기」(기본 끔)가 더해졌습니다.

## 0.1.2 (2026-10-14)

### 새 기능
- **회상**: 타이틀 화면의 회상 버튼 → 캐릭터 선택 → 그 캐릭터로 끝까지 본 이야기 이벤트를 다시 봅니다. 슬롯과 상관없이 계정 공용으로 기록하고, 장면이 끝나면 목록으로 돌아옵니다. 이전 버전에서 만든 슬롯의 진행은 처음 열 때 한 번 옮깁니다(확실히 본 이벤트만).
- **기록실**: 게임 메뉴 → 환경설정 탭의 몬스터도감 줄이 기록실로 바뀌었습니다. 몬스터 도감, 아이템 도감, 보스 기록과 보스 러시, 도전과제(원본 50개 + 추가 11개, 추가 도전과제 골드는 계정당 한 번), 출석·심연 기록을 봅니다.
- **대사**: 대사 로그, 자동 진행, 텍스트 속도, 페이지 끝 ▼, 확인 키를 누르고 있으면 빨리 넘기기(기본은 읽은 대사만, 읽은 대사는 표시).
- **조작**: 대사창의 LOG·AUTO 버튼에 쓰는 장치의 키(L/K 또는 패드 □/△)를 표시합니다. 필드에서 패드 D패드 →는 대사 로그, 키보드 K는 어디서나 자동 진행 켬/끔입니다.
- **HUD**: 비약 버프 아이콘과 남은 시간, 가까운 보스의 HP 바, 진행 중인 퀘스트 추적(퀘스트 상세의 추적 켬/끔으로 퀘스트마다 뺄 수 있음). HP·MP·EXP 수치도 있지만 원본에 없던 표시라 기본은 끔입니다.
- **장비·상점**: 가방에서 착용 장비 대비 증감 표시, 수량 −10 / +10 / 최대, 일괄 판매, 되사기.
- **지도·저장**: 미니맵의 퀘스트 NPC·공간이동석 아이콘, 지도의 퀘스트 목적지, 맵 이동 자동 저장(기본 끔), 슬롯 카드의 회차 표시.
- **설정**: 배경음·효과음 볼륨, 화면 흔들림·번쩍임 줄이기, 심연 도전(기본 끔).
- **콘텐츠**: 출석 보상(7일째 황금알), 차원의 문 심연(보스 처치 후 더 강한 층으로), 3회차.

### 바뀐 점
- 터치 기기에서는 풀스크린이 기본으로 켜집니다. 환경설정에서 직접 바꾸면 그 설정을 따릅니다. 이전 버전을 쓰던 기기도 한 번은 켜진 상태로 시작합니다.
- 시작 로고와 등급 안내는 원본처럼 흰 바탕이고, 풀스크린에서는 타이틀(슬롯·캐릭터 선택·회상 등의 배경 포함)이 좌우 여백까지 이어집니다.
- 타이틀 버튼은 게임순위 · 게임시작 · 회상 순서로, 게임시작이 화면 가운데에 옵니다.
- 쿠폰상점 HUD 버튼을 없앴습니다. 쿠폰상점은 차원의 문 아이콘(커뮤니티) 메뉴에 있습니다. 그 자리에는 대사 로그 버튼이 있습니다.

### 원본 재현·수정
- 보스를 잡은 뒤 다음 스토리까지 기다리는 10초 동안, 원본의 "다음 진행" 창과 줄어드는 빨간 막대를 보여 줍니다.
- 도움말 23/25(청소년요금)에서 ◀ ▶가 눌리지 않던 문제를 고쳤습니다.
- 모바일에서 화면을 누르면 옅은 파란색이 칠해지던 문제를 고쳤습니다.
- 풀스크린 여백에 있는 캐릭터의 감정 말풍선이 잘리던 문제를 고쳤습니다.
- 메뉴가 6개인 상점(초원마을 아이템상인 등)에서 버튼이 설명줄을 덮던 문제를 고쳤습니다.

### 저장 데이터
- 슬롯 세이브 형식은 바뀌지 않았습니다. 이전 버전의 세이브를 그대로 읽습니다.
- 계정 공용 기록(`grantria.records`: 도감·보스·러시·심연·본 이벤트)과 읽은 대사(`grantria.read`)를 새로 저장합니다. 데이터 관리의 JSON 백업에 함께 들어갑니다.
